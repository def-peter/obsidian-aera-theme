# Triage Labels

Skills 使用五个 canonical triage roles。下表定义这些 roles 与本仓库实际 labels 的映射。

| Canonical role    | Tracker label      | 含义                           |
| ----------------- | ------------------ | ------------------------------ |
| `needs-triage`    | `needs-triage`     | 等待 maintainer 评估           |
| `needs-info`      | `needs-info`       | 等待 reporter 补充信息         |
| `ready-for-agent` | `ready-for-agent`  | 信息完整，可交给 AFK agent     |
| `ready-for-human` | `ready-for-human`  | 需要由 human 实现              |
| `wontfix`         | `wontfix`          | 不会处理                       |

当 skill 提到 canonical role 时，使用对应的 tracker label。
